# PocketSmart AI

PocketSmart AI is a Generative AI-powered budgeting and recommendation platform.

It helps users plan their budget and receive personalized recommendations for:

- Home Interior Planning
- Party Budget Planning
- Jewelry Selection

## Features

- AI-powered budget allocation
- Personalized recommendations
- Estimated costs
- Remaining budget calculation
- Money-saving suggestions
- Shopping platform links
- Jewelry/outfit image upload
- Image-based jewelry recommendations
- Recommendation history
- Login and logout
- Input validation
- Secure Gemini API key using environment variables

## Technologies Used

- Python
- Flask
- Google Gemini API
- Google GenAI SDK
- HTML
- CSS
- JavaScript
- Python-dotenv
